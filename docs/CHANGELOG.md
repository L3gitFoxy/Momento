# Momento v9.4.0

## Highlights
* **Today Mode** — live current block with Done, Snooze 10m (cascades later blocks), Skip, focus lock, and end-of-day recap
* **Recovery plan** — when you fall behind on flexible blocks, one tap reshapes the rest of the day (keeps fixed classes; stops by evening)
* **Quests** — daily and weekly goals (blocks, focus minutes, to-dos); XP scales gently with level; no multipliers; only refresh at day/week end
* **Single-instance app** — a second launch offers to open the window that is already running
* **Polish** — themes apply to settings, footer links, mic, Day Flex, update card, and cosmetics; optional calm focus-lock background; Electron menu bar hidden

## Fixes
* Half XP for one-day-late to-dos uses calendar days again
* To-dos due today or tomorrow cannot be deleted
* Snooze no longer stacks over the next block’s start time
* “Add for” no longer shows a duplicate Next Monday on Mondays
* Streak Fire shows on the XP pill with a real flame animation when unlocked and streak ≥ 7
